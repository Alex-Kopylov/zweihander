# Documentation Language Guidelines

Shared instruction file. Every AI agent harness in this repository reads this
same file. Reference it by path. Never copy its content elsewhere.

## Rules

- Keep every detail. No fact, number, name, warning, exception, condition, or cross-reference may disappear.
- Keep the document's own language. Never translate, even though the standards below are written for English.
- Change nothing when the document already follows the styling below.
- Change wording and order only. Never change meaning.
- Keep any ambiguity as it is. Never guess an interpretation.
- Add nothing. No new sections, no new advice, no filler.
- Leave these untouched: code blocks, inline code, commands, URLs, link targets, anchors, YAML frontmatter, HTML comments, version numbers, dates, licence and legal text, badges, images, and the names of people, products, files, flags, and functions.
- Leave the release order and numbering of a `CHANGELOG.md` as they are. Rewrite the prose inside entries only.
- Report what you changed. Never claim success without naming it.

## Styling

Apply ISO 24495-1 (plain language), ASD-STE100 (Simplified Technical English),
W3C Cognitive Accessibility Guidance (COGA), and the US Plain Writing Act:

- Write one instruction per sentence.
- Use the active voice and name the actor.
- Use simple present or simple past.
- Cap a procedural sentence at 20 words and a descriptive sentence at 25.
- Write whole sentences with articles. Never write telegraphic notes.
- Use one meaning per word, and reuse that same word everywhere.
- Replace a rare word with a common word of the same meaning.
- Split a stack of three or more nouns with a preposition or a hyphen.
- Expand an abbreviation on first use, then use the abbreviation.
- Cap a paragraph at 6 sentences.
- Put a warning before the step it applies to, never after.
- Turn three or more parallel facts into a list or a table.
- Cap a list at 7 items. Split a longer list into named groups.
- Give every section a heading that states its subject, and keep heading levels in order.
- Lead each section with its outcome, then give the detail.
- Address the reader as "you", and state what to do before you explain why.
