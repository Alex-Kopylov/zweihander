# formal-verification

Formal verification of code: `statechart` checks a TLA+ model and draws it as
a Mermaid statechart; `create-formal-verification-skill` and
`maintain-formal-verification-skill` generate and maintain a project's own
formal checks.

Ported from pstack (MIT, Lauren Tan); see `third_party/THIRD_PARTY_NOTICES.md`
for provenance. `statechart`'s test corpus is not ported yet
(Alex-Kopylov/zweihander#176).
